Compete · Strategy

Quick tips

  • Rank missions by points per second.
  • Group nearby missions into 4–7 runs.
  • Use a jig to launch from the same spot.
  • Practise full 2:30 matches.
  • Charge the battery before every match.
  • Take photos and notes for judges.

first_run.py · SPIKE app 3
from hub import port
import motor, motor_pair, runloop

async def main():
    motor_pair.pair(motor_pair.PAIR_1, port.A, port.B)
    await motor_pair.move_for_degrees(motor_pair.PAIR_1, 720, 0, velocity=500)   # forward
    await motor_pair.move_for_degrees(motor_pair.PAIR_1, 180, 100, velocity=300) # turn
    await motor.run_for_degrees(port.C, 90, 600)                                 # arm

runloop.run(main())

drive.py
from pybricks.pupdevices import Motor
from pybricks.parameters import Port, Direction
from pybricks.robotics import DriveBase

left = Motor(Port.A, Direction.COUNTERCLOCKWISE)
right = Motor(Port.B)
arm = Motor(Port.C)
robot = DriveBase(left, right, wheel_diameter=56, axle_track=112)
robot.use_gyro(True)

robot.straight(400)      # mm
robot.turn(90)           # degrees
arm.run_angle(500, 120)
robot.straight(-400)
multitask.py
from pybricks.pupdevices import Motor
from pybricks.parameters import Port, Direction
from pybricks.robotics import DriveBase
from pybricks.tools import multitask, run_task

robot = DriveBase(Motor(Port.A, Direction.COUNTERCLOCKWISE), Motor(Port.B),
                  wheel_diameter=56, axle_track=112)
robot.use_gyro(True)
arm = Motor(Port.C)

async def main():
    await multitask(robot.straight(500), arm.run_angle(400, -90))  # at the same time
    await robot.turn(45)

run_task(main())
main.py
from pybricks.hubs import PrimeHub
from pybricks.parameters import Button
from pybricks.tools import wait

hub = PrimeHub()
hub.system.set_stop_button(Button.BLUETOOTH)

def run1(): print("run 1")
def run2(): print("run 2")
RUNS = [run1, run2]

i = 0
while True:
    hub.display.number(i + 1)
    pressed = hub.buttons.pressed()
    if Button.RIGHT in pressed:
        i = (i + 1) % len(RUNS); wait(250)
    elif Button.LEFT in pressed:
        i = (i - 1) % len(RUNS); wait(250)
    elif Button.CENTER in pressed:
        while hub.buttons.pressed(): wait(10)
        RUNS[i]()
        i = (i + 1) % len(RUNS)
    wait(20)

FAQ

Which kit do we need?

SPIKE Prime set + the season Challenge Set.

Blocks, Python or Pybricks?

Start with blocks. Then Python. Pybricks for the best precision.

Can adults build the robot?

No. Students build and code everything.

Robot drifts?

Stiffen the frame, use gyro driving, charge the battery.
